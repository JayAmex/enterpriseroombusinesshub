# Demo Video Script - Enterprise Room Business Hub

**Purpose:** Guide for recording a comprehensive demo video of the application

---

## 🎬 **Screen Recording Tools**

### Recommended (Free):
1. **OBS Studio** (Windows/Mac/Linux)
   - Free, open-source
   - High quality recording
   - Can stream too
   - Download: https://obsproject.com/

2. **Windows Built-in** (Windows 10/11)
   - Press `Windows + G` to open Game Bar
   - Click record button
   - Simple and built-in

3. **QuickTime Player** (Mac)
   - Built-in screen recorder
   - File → New Screen Recording

4. **ShareX** (Windows)
   - Free, open-source
   - Great for screenshots + video
   - Download: https://getsharex.com/

## 🎥 **Recording Tips**

### **Video Settings:**
- **Resolution:** 1920x1080 (1080p) or 1280x720 (720p)
- **Frame Rate:** 30fps (60fps if available)
- **Format:** MP4 (most compatible)
- **Audio:** Record system audio + microphone (if doing voiceover)

### **Presentation Tips:**
1. **Speak Clearly:** If doing voiceover, speak slowly and clearly
2. **Pause Between Sections:** Give viewers time to process
3. **Highlight Clicks:** Use cursor highlighting or zoom on clicks
4. **Show Loading States:** Don't edit out loading - shows real performance
5. **Keep It Natural:** Small mistakes are okay, shows authenticity

### **Editing Tips:**
- Add text overlays for key features
- Add transitions between sections
- Add background music (optional, keep it subtle)
- Add callouts/arrows for important features
- Keep total length: 8-10 minutes (or shorter highlights)
